# LocalDrop v1.0.0

LocalDrop is an Android app that hosts a text and file sharing page on a local network. Open the address shown by the phone in a browser, authenticate with the current six-digit access code, and share items between the phone and connected browsers.

## Features

- Share text and files between Android and authenticated browser clients.
- Upload one or multiple files, monitor transfers, and download received files.
- Copy, delete, or clear shared items; changes synchronize to connected clients through polling.
- Keep shared data in the app's private storage.
- Start the HTTP server as a foreground service and show its address and access code in the app.
- Choose light, dark, or system appearance.
- Use a responsive browser interface on desktop and mobile screens.

## Requirements

To run LocalDrop:

- Android 8.0 (API 26) or newer.
- A phone and browser connected to the same trusted local network.

To build LocalDrop:

- JDK 17.
- Android SDK Platform 36.

## Use

1. Install LocalDrop on the Android phone and open the app.
2. Tap **Start Server** and note the address and access code shown in the app.
3. Open that address in a browser on the same local network.
4. Enter the current access code to open the sharing dashboard.

The access code is generated by the running server; do not share screenshots or logs that expose it. See [SECURITY.md](./SECURITY.md) before using the app.

## Build and test

From the project root on Windows:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`. Automated tests include utility and Android UI tests as well as local HTTP API tests. These checks do not replace testing on physical phones, browsers, and Wi-Fi networks.

## Signed release builds

Release signing is read from the build process environment; credentials and the keystore must stay outside the source tree. Set all four variables using a secure local or CI secret store before running `.\gradlew.bat :app:assembleRelease`:

- `LOCALDROP_RELEASE_STORE_FILE` - absolute path to the existing release keystore.
- `LOCALDROP_RELEASE_STORE_PASSWORD` - keystore password.
- `LOCALDROP_RELEASE_KEY_ALIAS` - key alias.
- `LOCALDROP_RELEASE_KEY_PASSWORD` - key password.

If any value is missing, release packaging fails with the names of the missing variables. Never put their values in Gradle files, command-line arguments, documentation, or Git. A successful signed APK is written to `app/build/outputs/apk/release/app-release.apk`.

The application ID is `com.samir.localdrop`, the version name is `1.0.0`, and the version code is `1`. A release is not ready to distribute until a project owner supplies and safeguards signing credentials and verifies the resulting APK.
