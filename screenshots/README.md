# Screenshot checklist

No screenshots are included yet. Capture genuine screenshots from the actual app and browser when a physical-device/browser setup is available; do not create mockups that could be mistaken for product screenshots.

Suggested captures:

- Android server screen with the server stopped and running.
- Android access code hidden, then revealed, with the copy control visible.
- Browser login page and the shared-items dashboard with non-sensitive sample data.
- Browser file upload/transfer state and the Clear All confirmation dialog.
- A narrow mobile browser view and the available appearance themes.

Before adding an image, remove or obscure access codes, IP addresses, Wi-Fi names, real filenames, shared text, notifications, account details, and other personal information. Review image metadata for location or device details. Use fictional sample content and label any test-only environment clearly.
